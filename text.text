1. Spring StateMachine issues
   - StateMachine instances created per request
   - StateMachineFactory.getStateMachine() usage
   - StateMachineService usage
   - Missing stopReactively()
   - Missing releaseStateMachine()
   - StateMachinePersister or RuntimePersister retaining contexts
   - ExtendedState storing large objects

2. WebFlux issues
   - Manual subscribe() calls
   - cache(), replay(), share()
   - Sinks.Many/Sinks.One not cleaned up
   - Flux/Mono stored in static collections
   - Infinite Flux streams
   - DataBuffer leaks
   - ByteBuf leaks

3. Scheduler leaks
   - Schedulers.newParallel()
   - Schedulers.newBoundedElastic()
   - Executors created repeatedly
   - Scheduled tasks never cancelled

4. Cache leaks
   - ConcurrentHashMap without eviction
   - Caffeine caches without maximumSize
   - Guava caches
   - Static collections
   - ThreadLocal usage

5. Metrics leaks
   - Micrometer metrics with high-cardinality tags
   - Tags using requestId, userId, sessionId

6. Persistence leaks
   - JPA entities retained
   - Hibernate Session leaks
   - Large entity graphs in memory

Please identify:
- Classes that may retain objects
- Collections that grow indefinitely
- Objects stored in static fields
- Missing cleanup logic
- Potential references preventing GC

Provide exact code locations and recommendations.
